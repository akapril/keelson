# 界面国际化 (i18n) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 Keelson 用户可见文案支持中/英切换，覆盖 React 界面、Rust 托盘菜单与 MCP 系统通知，首次跟随系统、切换后记住。

**Architecture:** 前端 react-i18next（`import.meta.glob` 自动装载 `locales/<lng>/<ns>.json`，按 feature 分命名空间）统管 UI 文案；Rust 侧一份轻量 `key→{zh,en}` 映射管托盘/通知；前端每次语言变更经 Tauri command `set_locale` 同步给 Rust，Rust 即时重建托盘文案。

**Tech Stack:** i18next · react-i18next · i18next-browser-languagedetector · Tauri v2 (Rust) · vitest · Rust `#[cfg(test)]`。

## Global Constraints

- 语言集仅 `zh` / `en`；`fallbackLng: 'en'`；首次检测顺序 `localStorage` → `navigator`。
- 只抽取 **UI 展示串**；**中文源码注释一律保留不动**，非展示串（日志、内部 key、事件名）不动。
- key 用**语义化英文点号命名**（`board.task.create`），不用中文原文作 key。
- 英文译文由实现者产出**初版**（可后续润色）；每个 `zh/<ns>.json` 必有同结构 `en/<ns>.json`。
- 冻结内部代号与标识：`com.rework.app`、hook 标记（`rework-*`）、既有 localStorage 功能键、MCP server 名等一律不改。
- 不硬编码颜色，沿用现有中性主题 Tailwind 语义类。
- store 写失败重抛 + 调用点 toast（沿用现有约定）。
- 依赖固定：`i18next` `react-i18next` `i18next-browser-languagedetector`，不引入额外 i18n 相关包。

## Feature 迁移规程（Task 6–14 通用操作）

每个迁移批次针对一个命名空间 `<ns>`，操作一致，仅参数不同：

1. **发现文件**：`grep -rlP '[\x{4e00}-\x{9fff}]' <目标目录> --include='*.tsx' --include='*.ts'` 列出含中文文件。
2. **抽取 UI 展示串**：仅抽 JSX 文本、`placeholder`/`title`/`aria-label`/toast 文案、按钮/标签等**用户可见**串。**跳过**：注释、`console.*`、日志、内部常量 key、事件名。
3. **建资源**：把抽出的串写入 `src/i18n/locales/zh/<ns>.json`（值=原中文），并译出同结构 `src/i18n/locales/en/<ns>.json`。key 语义英文点号命名。含变量的用具名插值：`"session.count": "共 {{n}} 条会话"` / `"{{n}} sessions"`。
   - `index.ts` 用 glob 自动装载，**无需手动注册**新 json。
4. **改组件**：组件顶部 `const { t } = useTranslation("<ns>");`，把硬编码串替换为 `t("<key>", { 变量 })`。跨页通用串（如「保存」「取消」「删除」）优先复用 `common`：`useTranslation(["<ns>","common"])` 后 `t("common:action.save")`。
5. **测试**：为该批挑 1 个代表性组件加双语渲染测试（见下方范式），断言中文默认渲染 + 切到 `en` 后渲染英文。
6. **提交**：`git commit -m "feat(i18n): 迁移 <ns> 命名空间文案"`。

**双语渲染测试范式**（套用时替换 `组件`/`ns`/中英断言串）：

```tsx
// src/i18n/__tests__/<ns>.i18n.test.tsx
import { render, screen } from "@testing-library/react";
import i18n from "../index";
import { 组件 } from "@/features/<feature>/组件";

describe("<组件> i18n", () => {
  it("默认中文渲染关键文案", async () => {
    await i18n.changeLanguage("zh");
    render(<组件 {...最小必要 props} />);
    expect(screen.getByText("中文关键串")).toBeInTheDocument();
  });
  it("切换到英文后渲染英文文案", async () => {
    await i18n.changeLanguage("en");
    render(<组件 {...最小必要 props} />);
    expect(screen.getByText("English key string")).toBeInTheDocument();
    await i18n.changeLanguage("zh"); // 复原，避免污染其它用例
  });
});
```

> 若组件依赖 store/Provider，用现有测试里的最小挂载方式；无法独立渲染的组件改测其纯文案 map/函数。批次目标是「该 feature 无残留硬编码中文 UI 串」，测试是抽样保障非穷举。

```ts
// i18next 初始化：glob 自动装载 locales/<lng>/<ns>.json（加新命名空间只需加文件）。
// 语言变更（含首次）经 Tauri command set_locale 同步给 Rust 侧（托盘/通知）。
import i18n from "i18next";
import { initReactI18next } from "react-i18next";
import LanguageDetector from "i18next-browser-languagedetector";
import { invoke } from "@tauri-apps/api/core";

// 装载全部资源：路径形如 ./locales/zh/common.json
const files = import.meta.glob("./locales/*/*.json", { eager: true }) as Record<
  string,
  { default: Record<string, unknown> }
>;
const resources: Record<string, Record<string, unknown>> = {};
for (const path in files) {
  const m = path.match(/\.\/locales\/([^/]+)\/([^/]+)\.json$/);
  if (!m) continue;
  const [, lng, ns] = m;
  (resources[lng] ??= {})[ns] = files[path].default;
}

void i18n
  .use(LanguageDetector)
  .use(initReactI18next)
  .init({
    resources,
    supportedLngs: ["zh", "en"],
    fallbackLng: "en",
    defaultNS: "common",
    ns: Object.keys(resources.en ?? { common: {} }),
    detection: { order: ["localStorage", "navigator"], caches: ["localStorage"] },
    interpolation: { escapeValue: false }, // React 已防 XSS
  })
  .then(() => {
    // 首次启动同步当前语言给 Rust（非 Tauri 环境静默失败）
    void invoke("set_locale", { locale: i18n.language }).catch(() => {});
  });

// 后续切换同步
i18n.on("languageChanged", (lng) => {
  void invoke("set_locale", { locale: lng }).catch(() => {});
});

export default i18n;
```

```tsx
// 语言设置区：跟随系统 / 中文 / English。
// 「跟随系统」= 清除 detector 的持久化语言键后按 navigator 重新判定。
import { useState } from "react";
import { useTranslation } from "react-i18next";
import {
  Select, SelectContent, SelectItem, SelectTrigger, SelectValue,
} from "@/components/ui/select";
import i18n from "@/i18n";

const LNG_STORAGE_KEY = "i18nextLng"; // i18next-browser-languagedetector 默认键

type Choice = "system" | "zh" | "en";

function currentChoice(): Choice {
  return (localStorage.getItem(LNG_STORAGE_KEY) as Choice) ?? "system";
}

export function LanguageSection() {
  const { t } = useTranslation("settings");
  const [choice, setChoice] = useState<Choice>(() => currentChoice());

  function apply(next: Choice) {
    setChoice(next);
    if (next === "system") {
      localStorage.removeItem(LNG_STORAGE_KEY);
      // 按 navigator 重新判定：取首选语言前缀
      const sys = navigator.language.toLowerCase().startsWith("zh") ? "zh" : "en";
      void i18n.changeLanguage(sys);
    } else {
      void i18n.changeLanguage(next); // detector caches:['localStorage'] 会写回键
    }
  }

  return (
    <section className="space-y-3">
      <div>
        <h2 className="text-sm font-medium">{t("language.title")}</h2>
        <p className="mt-0.5 text-xs text-muted-foreground">{t("language.desc")}</p>
      </div>
      <Select value={choice} onValueChange={(v) => apply(v as Choice)}>
        <SelectTrigger className="w-full">
          <SelectValue />
        </SelectTrigger>
        <SelectContent>
          <SelectItem value="system">{t("language.followSystem")}</SelectItem>
          <SelectItem value="zh">中文</SelectItem>
          <SelectItem value="en">English</SelectItem>
        </SelectContent>
      </Select>
    </section>
  );
}
```

```rust
//! Rust 侧用户可见文案的极简中英映射：仅覆盖托盘菜单与 MCP 通知。
//! key 命名与前端语义一致；未知 key 或未知语言回退英文。

/// 按 locale 取文案。locale 取 "zh" 用中文，其余（含 "en"）用英文。
pub fn t(locale: &str, key: &str) -> &'static str {
    let zh = locale == "zh";
    match key {
        "tray.show" => if zh { "显示 Keelson" } else { "Show Keelson" },
        "tray.quit" => if zh { "退出" } else { "Quit" },
        _ => "",
    }
}

#[cfg(test)]
mod tests {
    use super::t;
    #[test]
    fn zh_and_en_and_fallback() {
        assert_eq!(t("zh", "tray.quit"), "退出");
        assert_eq!(t("en", "tray.quit"), "Quit");
        assert_eq!(t("fr", "tray.quit"), "Quit"); // 未知语言回退英文
        assert_eq!(t("zh", "nope"), "");           // 未知 key 空串（调用方自兜底）
    }
}
```

```rust
/// 前端语言变更时同步给 Rust：更新当前语言并即时重建托盘菜单文案。
#[tauri::command]
fn set_locale(state: tauri::State<AppState>, locale: String) -> Result<(), String> {
    *state.locale.lock() = locale.clone();
    if let Some(item) = state.tray_show.lock().as_ref() {
        let _ = item.set_text(i18n::t(&locale, "tray.show"));
    }
    if let Some(item) = state.tray_quit.lock().as_ref() {
        let _ = item.set_text(i18n::t(&locale, "tray.quit"));
    }
    Ok(())
}
```
